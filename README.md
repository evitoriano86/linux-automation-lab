Projeto prático de **automação em Linux**, utilizando **Bash Script**, **cron**, **logs**, **Git** e boas práticas de **administração de sistemas**.  
O objetivo é simular rotinas reais de um ambiente Linux corporativo, focando em monitoramento, automação e organização.

---

## 🎯 Objetivo

Criar um conjunto de scripts para:

- Monitoramento de recursos do sistema
- Automação de tarefas administrativas
- Geração de logs para auditoria e troubleshooting
- Organização de código com versionamento Git
- Simular cenários reais encontrados em ambientes corporativos Linux

Este projeto também serve como **material de estudo**, **laboratório prático** e **portfólio técnico**.
